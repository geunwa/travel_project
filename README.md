# 관광정보 API 조회 프로그램

## 1. 프로그램 개요

이 프로그램은 공공데이터포털의 관광정보 API를 활용하여  
사용자가 입력한 지역의 관광지, 문화시설, 음식점 정보를 조회하는 Python 프로그램입니다.

사용자는 다음 정보를 직접 입력할 수 있습니다.

- 지역명
- 조회할 콘텐츠 종류
  - 관광지
  - 문화시설
  - 음식점
- 페이지 번호

프로그램은 API에서 받은 JSON 데이터를 파싱하여 각 장소의 정보를 보기 쉽게 출력합니다.

---

## 2. 주요 기능

- 공공데이터포털 관광정보 API 호출
- 지역명 입력 기능
- 관광지 / 문화시설 / 음식점 선택 기능
- 페이지 번호 입력 기능
- JSON 응답 데이터 파싱
- 제목, 주소, 전화번호, 좌표 출력
- 입력값 검증
- 예외 처리
  - API 키 누락
  - 네트워크 요청 오류
  - 요청 시간 초과
  - JSON 파싱 오류
  - 잘못된 사용자 입력 처리

---

## 3. 사용 기술

- Python
- requests
- python-dotenv

---

## 4. 파일 구성

    travel_project/
    ├─ main.py
    ├─ utils.py
    ├─ README.md
    ├─ requirements.txt
    └─ .env.example

### 파일 설명

- `main.py` : 프로그램 실행 파일
- `utils.py` : API 요청, 입력 처리, 출력 관련 함수 모음
- `README.md` : 프로젝트 설명 및 실행 방법
- `requirements.txt` : 필요한 라이브러리 목록
- `.env.example` : API 키 입력 형식을 보여주는 예시 파일

---

## 5. 실행 방법

### 1) 프로젝트 폴더로 이동

터미널 또는 명령 프롬프트에서 프로젝트 폴더로 이동합니다.

    cd travel_project

### 2) 필요한 라이브러리 설치

아래 명령어를 실행하여 필요한 패키지를 설치합니다.

    pip install -r requirements.txt

### 3) API 키 설정

`.env.example` 파일을 참고하여 `.env` 파일을 직접 생성합니다.

`.env` 파일 예시:

    API_KEY=발급받은_서비스키

### 4) 프로그램 실행

아래 명령어로 프로그램을 실행합니다.

    python main.py

---

## 6. API 키 설정 방법

### 1) 공공데이터포털에서 서비스 키 발급

공공데이터포털에서 관광정보 API를 신청하고 승인받은 뒤 서비스 키를 발급받습니다.

### 2) `.env` 파일 생성

프로젝트 폴더에 `.env` 파일을 만들고 아래 형식으로 작성합니다.

    API_KEY=발급받은_서비스키

### 3) 주의사항

- 실제 API 키가 들어 있는 `.env` 파일은 가능한 한 제출하지 않습니다.
- 제출용으로는 `.env.example` 파일만 포함하는 것을 권장합니다.

제출용 `.env.example` 예시:

    API_KEY=YOUR_API_KEY

## 7. 프로그램 사용 방법

프로그램을 실행하면 순서대로 다음 입력을 받습니다.

### 1) 지역명 입력

예:

    부산

입력 가능한 지역 예시:

- 서울
- 부산
- 대구
- 인천
- 광주
- 대전
- 울산
- 세종
- 경기
- 강원
- 충북
- 충남
- 경북
- 경남
- 전북
- 전남
- 제주

### 2) 조회할 종류 선택

번호를 입력하여 조회할 종류를 선택합니다.

- `1` : 관광지
- `2` : 문화시설
- `3` : 음식점

예:

    3

### 3) 페이지 번호 입력

조회할 페이지 번호를 입력합니다.

예:

    1

## 8. 결과물 확인 방법

프로그램이 정상 실행되면 입력한 조건에 맞는 장소 정보가 목록 형태로 출력됩니다.

출력에서 확인할 수 있는 정보는 다음과 같습니다.

- 조회 지역명
- 조회 종류
- 전체 개수
- 현재 페이지 번호
- 현재 출력 개수
- 각 장소의 제목
- 주소
- 전화번호
- 좌표

### 출력 예시

    [부산] 음식점 조회 결과
    전체 개수: 329
    현재 페이지: 1
    현재 출력 개수: 10
    현재 범위: 1 ~ 10

    1. 음식점이름
       주소: 부산광역시 ...
       전화: 051-...
       좌표: (35.xxxx, 129.xxxx)

### 결과 확인 포인트

- 지역명이 내가 입력한 값과 맞는지 확인
- 선택한 종류(관광지/문화시설/음식점)가 맞는지 확인
- 전체 개수와 현재 페이지가 출력되는지 확인
- 장소별 제목, 주소, 전화번호, 좌표가 출력되는지 확인
- 페이지 번호를 바꿨을 때 다른 목록이 나오는지 확인
